# Misc Front-End Projects

A small collection of coursework and practice projects. Each project lives in its own folder and keeps its original README.

| Project | README | Notes |
| --- | --- | --- |
| [Inspira Find](inspira-find/) | [README](inspira-find/README.md) | Express and EJS app backed by MySQL. |
| [Learning Machine Learning](learning-machine-learning/) | [README](learning-machine-learning/README.md) | Express and EJS app with Gemini API integration. |
| [Quake Finder](Quake-Finder/) | [README](Quake-Finder/README.md) | Static site using Google Maps and the USGS API; configure a Maps key locally. |
| [Sign Up Page](Sign-Up-Page/) | [README](Sign-Up-Page/README.md) | Static form using external CSUMB web APIs. |
| [Guess It](Guess-It/) | [README](Guess-It/README.md) | Static number-guessing game; no build step. |
| [Pop Quiz](Pop-Quiz/) | [README](Pop-Quiz/README.md) | Static quiz; uses CDN libraries and browser local storage. |
| [ML Info Frontend](ML-Info-Frontend/) | [README](ML-Info-Frontend/README.md) | Static informational site; no build step. |
| [Express Solar System](express-solar-system/) | [README](express-solar-system/README.md) | Express and EJS app using NASA and Unsplash APIs. |

The three Express applications have their own package.json and lockfile. From the relevant project folder, install dependencies with npm ci and follow that project's README for its environment and startup requirements. The other five projects are static sites and do not need a build step.
